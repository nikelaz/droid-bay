# AGENTS.md

Instructions for coding agents working in this repository.

## Formatting

- Don't run `go fmt` / `gofmt` 
- Don't do column alignment - lining up struct fields, map literals, and composite literal keys into "tables" with elastic tabstops.

## Comments

- Do not add comments to the code. If something needs explaining, restructure or rename until it explains itself.
- This includes TODO/FIXME notes - if something needs doing, do it or open an issue instead of leaving a comment.
